## Technical Highlights

### Architecture:
```
User Upload X-ray
    ↓
Supervisor Agent (orchestrates)
    ↓
Detection Agent (YOLOv8 finds teeth)
    ↓
Measurement Agent (calculates dimensions)
    ↓
Clinical Agent (medical analysis)
    ↓
Report Agent (generates summary)
    ↓
Results (99.5% accurate, <1s total)
```

### Tech Stack:
- **Backend**: FastAPI, YOLOv8, TensorRT, LangChain, PyTorch 2.9.0
- **Frontend**: React 18 + TypeScript, WebSocket, Vite
- **Infrastructure**: Docker, NVIDIA Container Toolkit, Redis
- **Deployment**: Jetson Thor, Cloud (HuggingFace), CPU/GPU
